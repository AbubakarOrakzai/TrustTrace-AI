# LinkedIn video description

**Short video:** `docs/LinkedInVideo.mp4` — approximately 1 minute 18 seconds.

What happens when an instruction hidden in an invoice steers an AI agent
toward sending data outside the company?

This short TrustTrace AI demo shows a synthetic tool call being inspected and
blocked before execution, then shares an honest benchmark result: current
deterministic rules flagged zero of six attacks in the 12-row public sample.
That gap is a measure of what still needs work—not a claim of detection
success.

The video also shows a separate, verified synthetic inference using NVIDIA
Nemotron 3 Nano through Nebius Token Factory. The sample evaluation itself
does not call an external model.

This is an independent project demonstration, not sponsored or endorsed by
NVIDIA or Nebius.
